余额预警 / 数据备份（保存后即时生效，无需重启；WebUI 保存值优先于 config.yaml）

余额预警 已由 WebUI 覆盖

用户扣费后余额低于阈值时自动发站内通知（可选邮件）。同一用户在冷却期内只提醒一次。邮件依赖 SMTP 已配置。
0 = 关闭触发（等价于停用）

数据备份（PostgreSQL）已由 WebUI 覆盖

pg_dump 每日定时全库备份到 backups/ 目录，自动清理过期文件。备份目录（db_backup.dir）仅在 config.yaml 中配置。
点（服务器本地时间）
天（超期自动删除）

日志保留策略已由 WebUI 覆盖

每日定时分批删除超期日志，防止 usage_logs / audit_log 无限膨胀。保留天数填 0 = 不清理该表。保存后即时生效。
点（服务器本地时间）
天（usage_logs，0=不清）
天（audit_log，0=不清）

计费口径（真实 token 计费）已由 WebUI 覆盖

默认关闭 = 按字符口径计费（1 token ≈ 3 字符近似）。开启后每次响应完成时按上游返回的真实 usage 多退少补（预扣估算、结算真实），输入输出单价仍用「模型定价」表（含时段价）。缓存命中输入按折扣计价（DeepSeek 缓存命中约为未命中 1/10）。上游未返回 usage 的请求自动回落字符口径。保存后即时生效。
（命中输入价 / 未命中价，0.1 = 一折）

NapCat QQ 推送已由 WebUI 覆盖

通过 NapCat（OneBot 11）把余额预警、上游故障/恢复实时推送到 QQ。按服务地址协议头自动选通道：http(s):// 走 HTTP API，ws(s):// 走正向 WebSocket（跨公网用 wss:// 加密，证书配在 NapCat 侧）。access token 与 NapCat 侧网络配置保持一致。保存后即时生效。

邮件服务（SMTP）已由 WebUI 覆盖

注册验证码 / 密码重置 / 余额预警邮件的发送通道。保存后即时生效；密码仅写入，读取时以 ****** 显示。
SSL 直连（465）

上游健康探测已由 WebUI 覆盖

定时用小请求探测各上游，连续失败自动冷却、恢复自动摘除冷却。改后下一轮探测即生效，无需重启。

请求参数治理已由 WebUI 覆盖

对 chat / responses / Claude / completions 入口的请求参数做上限校验，超限直接 400 拒绝，防单请求刷爆计费。
0 = 不限制
